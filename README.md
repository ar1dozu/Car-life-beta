# CAR LIFE — Dushanbe District 01

A more complete early playable Godot 4 prototype. It is still a prototype, not a finished realistic game.

## Open
1. Extract the ZIP.
2. Open the folder containing `project.godot` in Godot 4.3 or newer.
3. Press Play (F6/F5 depending on editor view).

## Controls
- W / S: drive / brake and reverse when nearly stopped
- A / D: steering
- C: switch follow and cabin cameras
- On-screen buttons: hold to steer, brake, and drive (also intended for touch screens)

## What changed in v2
- Main scene builds the environment and car at runtime.
- Visible BMW E39-inspired sedan blockout instead of an invisible physics body.
- Wheels, collision shapes, road, sidewalks, buildings, distant hills, lighting and HUD.
- Mobile-friendly on-screen hold controls and camera button.
- GL Compatibility renderer selected for broad mobile support.

## Important
This ZIP contains source project files, not an APK. It has not been run through the Godot editor or exported to Android in this environment. Physics, touch layout and performance still need testing on an actual device. The car is an original primitive-mesh placeholder inspired by a sedan silhouette, not an exact BMW model.
